# Individual Annotation Samples

This directory contains per-image examples of original recordings and their annotated exports.

## Structure

| Image folder | Original archive | Annotation folder |
| --- | --- | --- |
| `DJI_0101/` | `original.zip` | `annotated/` with `Batch_1.zip` through `Batch_6.zip` |
| `DJI_0137/` | `Originial.zip` | `Annonted/` with `Batch_1.zip` through `Batch_5.zip` |

The folder and archive names above reflect the current repository contents, including the existing spelling in the `DJI_0137` sample.

## Notes

- Each ZIP is an archive; inspect its contents before assuming a particular internal file layout.
- Keep original and annotated archives paired by image ID.
- Preserve the existing source files when adding corrected exports; document which version is authoritative.
- Do not add restricted source images or annotations without permission.
