# Data

This directory contains selected field-image samples and annotation archives used by the project. The complete course dataset may be hosted separately.

**Dataset access:** [Course Sciebo folder](https://hshl.sciebo.de/s/g2QCsQzRqABPYmd)

## Directory contents

| Path | Contents |
| --- | --- |
| `initial_inspection_samples/` | Selected original field images and `Initial_inspection_samples_manifest.xlsx`. |
| `individual_annotation_samples/` | Per-image examples containing original image archives and annotated batch archives. |
| `mutual_annotated_samples/` | Shared image annotation exports grouped by annotator list (`annot_list_1/` and `annot_list_2/`). |

## Data notes

The files in this repository are selected samples and exports, not necessarily the complete source dataset. Access to the full dataset is provided through the course storage location.

Course data may be subject to access and redistribution restrictions.
