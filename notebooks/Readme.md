# Notebooks

Store the course-provided notebook and project analysis notebooks here.

## Suggested contents

- `ASB_lab_ADAS_01.ipynb` — course assignment notebook and scientific record for Task 1.
- Additional notebooks, if needed, for image inspection, manifest checks, mask validation, IoU calculation, or visualization.

## Notebook guidelines

- Preserve the instructor-provided requirements and terminology.
- Add code only where it supports reproducible inspection, quantitative analysis, validation, or visualization.
- Keep paths configurable rather than hard-coding a single machine's local directory.
- Do not commit restricted images or annotations into notebook outputs.
- Clear unnecessary outputs before committing if they expose restricted data or make the notebook excessively large.
- Explain each analysis step and distinguish actual results from examples or planned work.

If the original course notebook is stored elsewhere, document its location and do not create a misleading duplicate.
