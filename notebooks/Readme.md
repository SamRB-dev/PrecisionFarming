# Notebooks

Jupyter notebooks used for course work, data inspection, and reproducible analysis.

## Contents

| File | Purpose |
| --- | --- |
| `ASB_lab_ADAS_01-updated.ipynb` | Updated course notebook containing the assignment structure and the team's scientific record for ADAS Lab 01. |

Add further notebooks only when a separate, reproducible analysis is useful (for example, image inspection, manifest checks, mask validation, or metric visualisation).

## Notebook guidelines

- Preserve course requirements and terminology.
- Explain the purpose of each analysis cell and distinguish measured results from examples or plans.
- Keep paths configurable instead of relying on one machine's local directory.
- Record relevant package/tool versions when they affect reproducibility.
- Avoid committing unnecessary output, restricted images, or large embedded artefacts.
- Keep the notebook and any external scripts/data references consistent.

Run notebooks from the repository root unless the notebook explicitly documents another working directory.
