# Project management

- [Gantt chart](GANTT.md): generated schedule, contributor names, status, evidence and timeline.
- [Milestones](milestones.csv): forward-looking schedule.
- [Generator](generate_gantt.py): rebuilds the chart from the task log, scenario assignments and planning file.

Task 1 dates come from the task log. Scenario dates shown in the chart are commit-evidence windows only; the task log does not yet record scenario completion dates. Future milestones remain estimates unless marked official.
