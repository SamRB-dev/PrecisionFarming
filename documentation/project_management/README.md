# Project management

Project planning and progress tracking for Autonomous Systems B.

- [Gantt chart](GANTT.md): generated schedule, timeline and commit activity.
- [Milestones](milestones.csv): planned milestones and dates.
- [Generator](generate_gantt.py): rebuilds the chart from task-log and planning data.

The task log in `documentation/TASK_LOG.md` is the primary record for Task 1. Milestones.csv holds forward-looking estimates. Commit history provides supplementary evidence for scenario work but does not itself confirm official completion.
