# Documentation

This directory contains the scientific and practical documentation for the Precision Farming project.

## Recommended documents

- `annotation_guideline.md` — agreed labeling rules, class definitions, and procedures for ambiguous cases.
- `dataset_description.md` — data origin, selection strategy, annotation workflow, intended uses, and limitations.
- `tool_comparison.md` — comparison of the two annotation tools, measured setup/annotation/review times, export checks, and selection rationale.
- `validation_report.md` — image-mask checks, class-ID checks, class coverage, ignore-pixel coverage, and validation findings.
- `TASK_LOG.md` — task owners, start dates, deadlines, and completion dates.

Create these documents as work progresses and populate them with actual observations. Do not invent results or mark work as complete before it has been verified.

## Task log

See [TASK_LOG.md](TASK_LOG.md) for the team task tracker. Update the **Name**, **Date**, **Deadline**, and **When finished** fields as tasks are assigned and completed.
