# Experiments

This directory contains selected annotation-tool exports and derived visual comparison artefacts.

## Directory contents

| Path | Contents |
| --- | --- |
| `Cvat/` | Selected CVAT exports for sample images, including label metadata and rendered annotation masks. |
| `Label_Studio/` | Selected Label Studio annotation image exports. |
| `annotation_comparisons/` | Comparison PNGs generated by `utils/compare_annotations.py`, showing the original image and two annotation overlays. |

These are selected examples, not a complete dataset or a formal evaluation of annotation quality.
