# Annotation Comparisons

This directory contains comparison images generated by `utils/compare_annotations.py`.

Each comparison uses an original field image and matching ZIP exports from `data/mutual_annotated_samples/annot_list_1/` and `annot_list_2/`. The output shows the original image and the two annotator overlays side by side.

| Output pattern | Meaning |
| --- | --- |
| `<image-id>_comparison.png` | Comparison view for one image ID. |

Regenerate the comparisons from the repository root:

```bash
python -m pip install -r utils/requirements.txt
python utils/compare_annotations.py
```

These visualisations show differences between annotations. They are not a quantitative agreement metric or proof that either annotation is correct.
