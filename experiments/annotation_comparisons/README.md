# Annotation Comparisons

This directory contains comparison images generated by `utils/compare_annotations.py`.

Each comparison is built from an original field image and the matching ZIP exports in `data/mutual_annotated_samples/annot_list_1/` and `annot_list_2/`. The output shows the original image and the two annotator overlays side by side for visual inspection.

| Output pattern | Meaning |
| --- | --- |
| `<image-id>_comparison.png` | Comparison view for one image ID. |

To regenerate the comparisons, run the script from the repository root:

```bash
python -m pip install -r utils/requirements.txt
python utils/compare_annotations.py
```

These visualisations help identify differences between annotations; they are not a quantitative agreement metric or proof that either annotation is correct.
